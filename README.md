# Nail Artistry by Riya — Demo Website

A premium, responsive Next.js App Router website concept for Nail Artistry by Riya, Chennai.

## Run locally
1. Install Node.js 20 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Production build
Run `npm run build`, then `npm start`.

## Before publishing
- Confirm the Instagram profile URL and WhatsApp number.
- Replace the demo email `hello@riyanailartistry.com` with the client's preferred email.
- Confirm all service prices, add-on rates, home-service coverage and appointment policies.
- Replace/correct portfolio photos with original, high-resolution client-approved images.
- Add a real domain and hosting (Vercel is a straightforward Next.js option).

## Enquiry behaviour
The booking form validates the visitor's name and opens WhatsApp with the enquiry details pre-filled. No backend or database is required for this demo. Appointment confirmation happens directly with the business.

## Stack
Next.js 15, React 19, TypeScript, custom CSS, Lucide icons.
